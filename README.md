A program that writes one funny name for a band made of robots, plus a
few words on its hit song, to `/output/entry.txt`, for the make.fun
competition
[Name the Robot Band](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 100 characters, inside the 1 to 200 gate, a
single line with no em dash.

## The entry

```
The Roombas, whose hit 'Bump Into You' is a love song about crashing into the same wall every night.
```
